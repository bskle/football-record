# UI Prototype Validation: 踢球履历

## 原型目标

验证比赛记录主流程在 iPhone 与 Watch 双端信息架构下是否易于理解，且事件操作能即时反馈。

## Mock 数据

预置 1 场进行中比赛（2:1、52 分钟、43 分钟出场、4.6 km、142 bpm）和 3 场历史比赛，包含进球、上下场、胜平负。

## 结论

Watch 快速页采用两行两列四按钮，一次点击直接记录，最后一条快捷记录可持续撤销。乌龙类型仅在赛后补录中保留。预览资源带版本参数以避免旧脚本缓存。原生 Apple API、CloudKit、HealthKit 和真实离线同步仍需单独做技术 Spike，不属于本轮界面验证。
