# UI UX Spec: 球历前端原型

中文正式名：球历；英文正式名：`football-record`。英文名称不代表已设定 Bundle ID。

## 视觉与设备画布

界面定位为球场实时工具，使用 Apple 原生系统字体。墨绿用于状态和浅底手机的强调色；酸绿仅用于深色 Watch 的主要动作，数值与操作按使用优先级排布。

iPhone 使用 390×844 的逻辑画布；45mm Watch 使用 198×242 pt 的逻辑画布，对应 396×484 的物理像素。Watch 根据逻辑尺寸重新排版，不整体缩小旧页面。浏览器预览用于检查比例和布局，不承诺屏幕上的物理 1:1 大小。两张 Watch 同时展示，各自在设备画布外显示独立页面标题。

| MATCH-02 | Watch | 点击我进球/我助攻/进球/失球，一次完成 | 比分和个人归属即时更新，无确认弹窗 | 撤销最后一条快捷记录，恢复比分和个人统计 |

| ROUTE-02 | 手机赛后路线页 | 在地图选择/调整场地四角与朝向→保存当前场地→复用或清除 | 校准仅叠加真实场地边界；原始坐标及轨迹位置不变，清除后恢复未校准 | 无底图明确提示，不能用虚构球场替代；无需赛前校准 |

| 历史 | 单页 tab=history | HistoryCard | 有数据、空数据 | mock | 卡片宽度自适应 |
| 单场详情 | detailMatchId | DetailScore、Timeline、RouteButton | 可编辑、无事件、路线有/无数据 | mock | 出场时长以 HH:MM 展示且无单位；距离标题为“距离(km)”、数值不带单位；路线为完整可点按钮 |
| 比赛路线 | 单场详情内 route 子页面 | 返回比赛详情、GPSRoute、DurationHeatmap、RouteCalibration | 两图、只有 GPS、未记录路线、底图加载失败、未校准/已校准 | mock GPS；真实地图瓦片按服务约定加载 | 手机内独立页可滚动；两图同时展示不轮播；四角校准可选且仅在赛后操作 |

| 联系作者 | 设置页内 contact 子页面 | 返回设置、GroupQRCode、EmailLink | 二维码已提供/待提供 | 无需应用账号 | 手机画布内单列，可滚动 |
| Watch | 右侧预览 | WatchHome、ScoreActions | running、paused、无比赛 | mock | 45mm 198×242 pt 逻辑画布（396×484 物理像素）；两页同时展示并有外部标题，窄屏换行 |

Watch 首页包含紧凑比分、比赛时间和上场时间、心率/距离/速度/GPS，只有“上场/下场”和“比赛控制”两个操作按钮。快速页顶部显示当前比分及个人进球、助攻；中间为两行两列四个 44pt 高按钮；底部保留最后一条记录的撤销入口。快速页不展示最近事件列表，列表在手机端查看。

历史单场详情中，出场时长 68 分钟显示为 `01:08`、64 分钟显示为 `01:04`，不追加“分钟”或其他单位。距离标签为“距离(km)”，有数据时数值只显示数字；缺失的数据显示“未记录”，不显示为 0。

路线页默认使用真实地理底图，按原始位置与等比例米制尺度叠加轨迹；未校准时不画标准球场线，不将轨迹吸附、拉伸或归一化为标准矩形。无可用底图时明确显示缺失状态，不虚构球场。实际服务的署名与加载状态需保留。模拟 GPS 数据包含经纬度、采样时间、horizontalAccuracy、漂移点、采样缺口和替补席休息，用于验证展示与过滤规则，原始 rawGPS 保持不变。

展示前按水平精度与异常跳点过滤，断采分段、不跨缺口连线；有效样本不足时显示未记录或未生成，不补造路线。热力图以真实米制网格累计停留时长，降低模糊并使用统一淡黄、橙、红层次；按采样真实时间与上场/比赛运行区间求交，排除场下、比赛暂停和断采间隔，不把长采样间隔当成原地停留，也不直接用扣除了暂停的比赛钟代替采样时间。场下健康采集与健康数据显示仍继续，不因热力图统计口径而停止。

赛后可在手机地图选择四角、缩放地图并用 1 米微调修正边界/朝向；重复角点不得保存。配置按当前场地持久化，附近同场地复用，远处场地不误用；清除配置即恢复未校准视图。校准只决定真实边界叠加，不更改 rawGPS，也不把球场外位置挪回场内。第一场预置历史提供路线和热力图；第二场仅提供 GPS 路线，热力图区显示“未生成”；第三场无路线，显示“未记录”。实时页“GPS 良好”仅表示定位状态，已保存比赛的运动轨迹在“历史→比赛详情→路线”查看。原型展示不代表真实 HealthKit 采集或精确战术分析已实现。

前两场历史使用“北京理工大学足球场”的公开位置作为模拟中心 `39.95797595, 116.30951875`，来源为 [OpenStreetMap way 352009346](https://www.openstreetmap.org/way/352009346) 与 [OSM 原始坐标数据](https://api.openstreetmap.org/api/0.6/way/352009346/full.json)，不是用户实测轨迹。仅 HTTP 预览中的 mock 数据请求 OSM 瓦片；本地 file 入口保留核心交互并明确无底图，非 mock GPS 不外发到该瓦片服务。正式 MapKit/HealthKit 接入仍需真机验证。

## 可访问性

快速记录为两行两列四个按钮，不显示乌龙球快捷按钮；乌龙类型仍保留在赛后补录表单。我的进球、我的助攻各自包含我方比分 +1，不需要再点击进球。快捷记录使用显式 scorer/assister 字段，个人统计不从备注文字推导；最后一条快捷记录的撤销持续可用，不自动倒计时消失。

| 项 | 标准 | 验证方式 |
|---|---|---|
| 操作控件 | 使用 button 和 aria-label | 浏览器可访问性树 |
| Watch 快捷按钮 | 四按钮各高 44pt，在 198×242 pt 画布内完整显示 | 布局尺寸与截图检查 |
| 状态提示 | toast 使用 aria-live=status | 浏览器可访问性树 |
| 对比度 | 深色 Watch 主要动作使用酸绿，浅色 iPhone 强调色使用深绿 | 视觉检查 |
