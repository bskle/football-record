# GPS 与热力图修订

用户已批准上一轮建议：真实比例与方位、不预设标准场地、漂移与断采处理、仅上场且比赛运行时生成热力图、减弱模糊、赛后可选场地校准。

1. 先增加行为检查，验证物理比例、精度过滤、断采、墙钟暂停交集与校准持久化。
2. 使用统一 Web Mercator 投影比例，展示分段轨迹；没有校准时不画足球场线。模拟数据可请求当前视口的 OSM 底图，真实数据不外发。底图不可用时明确提示，轨迹独立可用。
3. GPS 与上下场/暂停事件使用独立墙钟 elapsedSecond；有效采样按上场与运行时间交集累计米制网格热度。缺时间、缺精度或旧暂停记录不完整时不给出虚假热图。
4. 赛后标记四个角点并检查凸四边形，按场地名称及附近位置复用；浏览器保存失败时说明限制，不改写原始 GPS。
5. 桌面与375px预览实际点击、保存/刷新/清除校准、缺数据和手表回归，保存截图并更新验收记录。

分工：根代理 app.js、index.html、验收；样式代理 styles.css；测试代理 tests/routes.test.cjs；文档代理产品方案、UI规范、README、冒烟清单。原型仍使用模拟采样，未接入原生地图或运动采集。

实施完成：41/41行为检查与语法通过；桌面、375px、校准保存/刷新/清除、缩放/重复角点禁存、暂停继续结束后双图、缺数据与快记隔离已验收。HTTP断网使用DOM模拟检查降级，不声称真实断网与原生真机验收通过。截图与具体边界见ui-prototype-validation.md。
