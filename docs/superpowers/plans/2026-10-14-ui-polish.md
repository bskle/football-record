# 可操作原型界面打磨

用户已同意先打磨一版查看。沿用现有“球场实时工具”的业务与配色，不新增记录步骤。

1. 纠正逻辑画布：手机以 390×844 pt 为基准，45mm Apple Watch 为 198×242 pt。设备外壳独立，两张手表页面同时展示，内容直接重新排版，不整体缩小。
2. 比赛页去掉重复计时与装饰，压缩比分、计时和健康数据的布局。首页仍只有上场/下场与比赛控制两项操作，健康数据与上下场无关。
3. 快速页保留四个 2×2 单击记录按钮，每个高度至少 44 pt。去掉手表事件列表，保留记录反馈与持续撤销；事件列表继续展示在手机。
4. 使用系统字体，提高次要文字对比，保留深色手表与暖白手机的运动工具风格。联系作者二维码和邮件入口继续可用。
5. 更新原来的浏览器标签，运行现有行为测试，并检查大窗口和窄窗口截图、实际画布尺寸、点击区域、计时暂停、上下场、比分与撤销、结束后再次开始。

本轮只打磨浏览器原型。结束时间修正和手机异常结束仍按已确定产品方案留待后续实现。
