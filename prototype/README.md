# 球历前端原型

中文正式名：球历；英文正式名：`football-record`。英文名称不代表已设定 Bundle ID。

推荐用 HTTP 预览查看真实地图。在项目根目录运行：

```bash
python3 -m http.server 4174 --bind 127.0.0.1 --directory prototype
```

然后打开 <http://127.0.0.1:4174>。本机系统 Python 如提示 Xcode 许可，可使用 `/opt/homebrew/bin/python3` 替代 `python3`。HTTP 地址仅在服务运行时可用。无需服务时，可双击根目录的 `打开足球记录.html` 或打开 `prototype/index.html`：file 入口核心交互仍可用，但明确不加载底图，不以虚构球场代替。比赛使用内存 mock 数据，刷新会恢复初始比赛；场地校准独立保存以供复用。

预览使用 iPhone 390×844 逻辑画布与 45mm Apple Watch 198×242 pt 逻辑画布；Watch 对应 396×484 物理像素。Watch 按逻辑尺寸重新排版，不整体缩小旧页面。浏览器用于检查比例和布局，不承诺物理 1:1 大小。两张 Watch 同时展示，每页标题独立放在设备画布外。

视觉方向为球场实时工具：使用 Apple 原生系统字体，墨绿表示状态并作为浅底手机强调色，酸绿仅用于深色 Watch 的主要动作。比赛主页与实时健康数据合并在第一张 Watch 卡片，内容包括紧凑比分、比赛/上场双时钟、心率、距离、速度和 GPS；只显示上场/下场与比赛控制两个操作按钮。

计时规则：比赛运行时比赛时间递增；上场时上场时间递增；比赛暂停时两个时间一起冻结；下场只停止上场时间；心率、距离、速度和 GPS 始终显示。

快速页顶部显示当前比分和个人进球、助攻，四个 44pt 高按钮以两行两列排列：我进球、我助攻、进球、失球。点一次立即保存并同步比分，无确认弹窗。我的进球和我的助攻同时包含我方比分 +1；下方持续提供最后一条记录的撤销入口，保留到下一条快捷记录。快速页不展示最近列表，事件列表在手机查看。1000ms 内重复点击不再次计分。乌龙球不占快捷按钮，赛后补录仍可选择乌龙类型。

设置中的“联系作者”可打开 QQ 交流群与邮件联系页面。邮箱为 `japdie19450815@qq.com`，邮箱地址和“发送邮件”按钮使用 `mailto:`，由用户的邮件应用起草。真实 QQ 群二维码源自 `data/用户反馈群邀请二维码/1.jpg`（内容实际为 PNG），原字节复制到 `prototype/assets/feedback-group-qr.png`；页面通过 CSS 放大展示二维码区域，保留完整码和周围留白。“保存二维码图片”提供完整原图，可在 QQ 中识别。更换不同构图的二维码图片时同步调整 `.contact-group-qr` 的显示位置。

历史单场详情的出场时长使用 HH:MM，无单位，例如 68 分钟为 `01:08`、64 分钟为 `01:04`。距离标题为“距离(km)”，有数据时数值只显示数字，缺失则显示“未记录”。

运动轨迹入口为“历史→某场比赛详情→路线”。路线以完整按钮进入手机内独立页面，可返回原比赛详情；GPS 路线图和可选热力图同时显示，不轮播。实时页“GPS 良好”表示定位状态。默认在真实地理地图上按原位置、等比例尺度叠加模拟 GPS 轨迹；未校准不画标准球场线，不把轨迹拉伸或吸附进标准矩形。第一场历史提供两图，第二场只有 GPS 并标明热力图“未生成”，第三场显示路线“未记录”；缺数据时不补造 0、轨迹或密度。

2026-10-15 新一轮规格：模拟样本包含 horizontalAccuracy、漂移点、采样缺口与替补席休息。展示会过滤低精度和异常跳点，断采分段且不跨缺口连线，原始 rawGPS 不变。热力图使用真实米制网格、减少模糊并增加密度层次，只统计上场且比赛运行的停留时长，排除场下、暂停与断采间隔；场下健康采集和数据显示继续。缺采样时间不能产生停留热度。

可选的场地校准在手机赛后进行：选择四角与朝向、缩放地图，并以 1 米步长微调；四角重复时不可保存。保存后刷新仍保留，附近同场地可复用、远处场地隔离，或清除后恢复未校准状态，不要求赛前操作。校准只叠加真实场地边界，不改 rawGPS 或改变轨迹位置。热力图统一使用淡黄、橙、红，采样真实时间与上场/比赛运行区间求交后累计。

前两场模拟位置使用北京理工大学足球场公开地图中心 `39.95797595, 116.30951875`，取自 [OSM way 352009346](https://www.openstreetmap.org/way/352009346) 及其[原始坐标数据](https://api.openstreetmap.org/api/0.6/way/352009346/full.json)，不是用户实测。只有 HTTP 预览的 mock 数据请求 OSM 底图，并显示署名；file 入口无底图，非 mock 真实 GPS 不向该服务外发。正式 MapKit/HealthKit 尚未接入。
